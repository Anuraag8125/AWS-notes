# AWS- Self Notes
Perfect — thanks for the details! Here's a **structured 10-week AWS DevOps course plan** designed to get you job-ready for entry-level roles.

---

### 🔹 **WEEK 1–2: Core Linux, Git & Networking**

✅ Goal: Foundation for all DevOps tools.

* **Linux**

  * Learn: file system, permissions, SSH, cron, package managers (apt/yum)
  * Resource: [Linux for Cloud & DevOps Engineers (YouTube - TechWorld with Nana)](https://www.youtube.com/watch?v=IVquJh3DXUA)

* **Git & GitHub**

  * Concepts: cloning, branching, PRs, rebasing, GitHub Actions (intro)
  * Practice: Make your GitHub profile strong

* **Networking Basics**

  * Learn: IP, DNS, HTTP/HTTPS, NAT, load balancing
  * Resource: [Networking for DevOps (FreeCodeCamp)](https://www.youtube.com/watch?v=qiQR5rTSshw)

---

### 🔹 **WEEK 3–4: AWS Deep Dive**

✅ Goal: Be fluent in core AWS services DevOps teams use.

* **EC2, VPC, IAM, S3, CloudWatch, CloudTrail, RDS, Route53**

* Resource: [AWS Certified Cloud Practitioner - FreeCodeCamp](https://www.youtube.com/watch?v=3hLmDS179YE)
  (Skip services you already know)

* **Hands-on**:

  * Host a static website in S3
  * Create a custom VPC + EC2 + security groups
  * Deploy a 2-tier app (web + DB)

---

### 🔹 **WEEK 5–6: Docker + CI/CD with Jenkins/GitHub Actions**

✅ Goal: Automate builds and containerization.

* **Docker**

  * Concepts: images, containers, volumes, networks, Dockerfiles
  * Resource: [Docker Crash Course (TechWorld with Nana)](https://www.youtube.com/watch?v=3c-iBn73dDE)
  * Project: Dockerize a Node.js or Python app + push to Docker Hub

* **CI/CD**

  * Jenkins (freestyle + pipeline), GitHub Actions (basics)
  * Resource: [Jenkins for Beginners - FreeCodeCamp](https://www.youtube.com/watch?v=fxKRnfMyrfQ)
  * Project: Build a CI/CD pipeline to deploy Docker app to EC2

---

### 🔹 **WEEK 7–8: Infrastructure as Code (IaC) + Monitoring**

✅ Goal: Automate infrastructure & track performance.

* **Terraform**

  * Create EC2, S3, IAM using IaC
  * Resource: [Terraform for Beginners (FreeCodeCamp)](https://www.youtube.com/watch?v=SLB_c_ayRMo)

* **CloudWatch & Logging**

  * Alarms, metrics, centralized logging
  * Resource: AWS official docs + practice dashboards

* **Project**: Build an infrastructure using Terraform to auto-deploy your app

---

### 🔹 **WEEK 9–10: Project + Resume + Interview Prep**

✅ Goal: Final portfolio + apply to jobs.

* **Project Ideas** (Choose 1 or 2):

  * CI/CD pipeline deploying Docker app to AWS using GitHub Actions + Terraform
  * End-to-end pipeline: GitHub → Jenkins → Docker → ECR → ECS
  * Monitoring + alerts with CloudWatch + custom dashboards

* **Resume**:

  * Tailor with keywords like: *AWS, CI/CD, Docker, Terraform, Jenkins, Linux*

* **Interview Prep**:

  * [DevOps Interview Questions (InterviewBit)](https://www.interviewbit.com/devops-interview-questions/)
  * Behavioral questions using STAR method

---

### ✅ Bonus Tips:

* Create a **GitHub portfolio** with markdown docs explaining each project
* Post your project walk-throughs on **LinkedIn**
* Get a **mock interview** from a mentor/friend or use Pramp.com
